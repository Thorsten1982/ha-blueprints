# Home Assistant Blueprints

Meine Sammlung benutzerdefinierter Blueprints für Home Assistant.

## Dynamische Lüftung (AH-basiert, Optimiert v2)

Berechnet die absolute Feuchtigkeit (AH) nach der Magnus-Formel und empfiehlt Stoßlüften, wenn die Außenluft trockener ist als die Innenluft.

[![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2FThorsten1982%2Fha-blueprints%2Fblob%2Fmain%2Fdynamic_ventilation_optimized.yaml)
